# 原型页面状态说明

原型文件：`docs/02-原型设计/index.html`（纯静态、可点击切换状态，用模拟数据演示主要操作、结果与异常状态）。

## 页面 → 题面映射

| 标签页 | 覆盖题面要求 |
| --- | --- |
| 宠物主人 | 时段名额展示、预约/支付/取消入口、订单与退款状态展示（角色：宠物主人） |
| 前台/服务人员 | 核销前置条件（已确认、无待审取消、本店）、开始/完成登记、重复操作拒绝 |
| 客服处理 | 临近开始取消待审核、退款失败重试、异常支付处理 |
| 店长日清 | 时段创建、未到店标记、收店核查（已服务/取消/未到店/退款待处理 + 金额核查） |
| 异常与状态说明 | 状态机全图 + 异常场景预期结果表 |

## 关键状态展示

- 待付款（含剩余时间）/ 已确认 / 取消待审核 / 已取消（含退款子状态）/ 已核销 / 服务中 / 已完成 / 未到店 / 超时关闭 / 异常支付。
- 金额口径：应支付、已支付、退款中、已退款、退款失败，与流水一致。
- 权限展示：非本店员工看不到数据；用户只能看本人记录。
